# Nova Chess

Статическая версия сайта шахмат, готовая для GitHub Pages.

## Запуск
1. Создай GitHub repository.
2. Загрузи `index.html`, `style.css`, `app.js`.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.

Сейчас кнопки комнаты работают как интерфейс-заглушка, а шахматная доска работает локально.
Для настоящей игры между разными устройствами понадобится отдельный WebSocket-сервер.
